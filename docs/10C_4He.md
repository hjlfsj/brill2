# 10C+4He — 10C+4He 符合测量与 14O 激发能重建

## 功能概述

10C+4He 符合测量分析，用于研究 14O 的激发态。程序分为两个阶段：

- **extract_10C_4He**：从 match/beam/track/ingot 等原始数据中提取 10C+4He 符合事件，经筛选和能量刻度后输出自包含的 ROOT 文件
- **GUI_10C_4He**：交互式 GUI，读取 extract 阶段的输出文件，进行可视化筛选和物理分析，包括 14O 激发能谱重建

## 探测器布局与能量定义

10C+4He 符合事件中，10C 和 4He 两个碎片击中不同的探测器层：

| 探测器 | 碎片 | 能量变量 | 说明 |
|--------|------|----------|------|
| T0 D1 | 10C + 4He | e1_10C, e1_4He | 第一层 DSSD，两个 hit 同时击中 |
| T0 D2 | 10C + 4He | e2_10C, e2_4He | 第二层 DSSD，两个 hit |
| T0 D3 | 10C + 4He | e3_10C, e3_4He | 第三层 DSSD，两个 hit |
| T0 D4 | 4He | e4_4He | 第四层 DSSD，4He 停止 |
| T0 S1 | 4He | e5_4He | CsI 闪烁体，4He 残余能量 |

10C 总动能：T_10C = e1_10C + e2_10C + e3_10C
4He 总动能：T_4He = e1_4He + e2_4He + e3_4He + e4_4He + e5_4He

## extract_10C_4He — 数据提取

### 运行方式

| 参数 | 说明 |
|------|------|
| `-r, --run` | 起始 run 号（必填） |
| `-e, --end-run` | 结束 run 号（可选，默认等于起始 run） |
| `-t, --trigger` | 触发类型：`main` 或 `t1`（必填） |
| `-c, --config` | 配置文件路径（默认 `config.toml`） |
| `--d1_hit` | D1 上 hit 数：`1`=仅 10C（4He 在 D1 丢失），`2`=两者都有（默认） |
| `-h, --help` | 打印帮助信息 |

### 示例

```bash
# 默认模式（d1_hit=2，两个碎片都击中 D1）
./extract_10C_4He -r 57 -e 70 -t main

# D1 仅 10C 模式（4He 在 D1 上丢失能量）
./extract_10C_4He -r 57 -e 70 -t main --d1_hit 1
```

### 输入文件

每个 run 需要读取以下文件（从 workspace 对应目录）：

| 文件 | 来源 | 内容 |
|------|------|------|
| `match/t0d1_<trigger>_<run>.root` | match_dssd | D1 正反面匹配事件 |
| `match/t0d2_<trigger>_<run>.root` | match_dssd | D2 正反面匹配事件 |
| `match/t0d3_<trigger>_<run>.root` | match_dssd | D3 正反面匹配事件 |
| `match/t0d4_<trigger>_<run>.root` | match_dssd | D4 正反面匹配事件 |
| `ingot/t0s_<trigger>_<run>.root` | 原始数据 | S1 CsI 事件 |
| `beam/beam_<trigger>_<run>.root` | sort_beam | 束流粒子分类 |
| `track/ppac_<trigger>_<run>.root` | track_ppac | PPAC 径迹 |
| `calibration/t0.txt` | calibrate_t0 | T0 能量刻度参数 |

### 输出文件

输出到 `workspace/10C+4He/` 目录（由 `config.toml` 中 `[paths]` 的 `10C_4He` 配置）：

```
extract_10C_4He_<trigger>_<run_start>_<run_end>.root       # d1_hit=2（默认）
extract_10C_4He_<trigger>_<run_start>_<run_end>_d1hit1.root # d1_hit=1
```

输出文件包含：
- **TTree `tree`**：C10He4Event 结构体，含能量、角度、束流分类、PPAC 径迹等全部信息
- **6 个 TH2D**：E1-E2、E2-E3 的 10C 和 4He 能量关联图，以及 4He 的 E3-E4、E4-E5 关联图

### 事件筛选流程

```
读取各探测器数据
    │
    ├── Pass10C_d3_4He_s1Cut 筛选：
    │   ├── d1.num == d1_hit（默认 2，可选 1）
    │   ├── d2.num == 2
    │   ├── d3.num == 2
    │   ├── d4.num == 1
    │   ├── 对 d1/d2/d3 的 hit 按能量排序
    │   ├── (E3_10C, E2_10C) 落在 cal_d2_d3_stop_10C_cut 内
    │   └── t0s.valid == true
    │
    ├── 碎片识别：能量大的 hit 为 10C，能量小的为 4He
    │   （d1_hit=1 时，d1 唯一 hit 即 10C，e1_4He=0）
    │
    ├── 能量刻度：CalibrateC10He4Energy(calib, layer, raw)
    │
    ├── 角度计算（依赖 PPAC 径迹）：
    │   ├── theta_beam, phi_beam：束流入射方向角
    │   ├── theta_10C：10C 相对于束流方向的散射角
    │   ├── theta_4He：4He 相对于束流方向的散射角
    │   └── opening_angle：10C 与 4He 之间的张角
    │
    └── 填充输出 TTree 和直方图
```

### d1_hit 参数说明

当 `d1_hit=1` 时，D1 上只有一个 hit，该 hit 被认定为 10C（4He 在 D1 上丢失能量）。此时：

- `e1_10C` = D1 上唯一 hit 的刻度能量
- `e1_4He` = 0
- 4He 总动能仅包含 e2 到 e5：T_4He = e2_4He + e3_4He + e4_4He + e5_4He
- 输出文件名添加 `_d1hit1` 后缀以区分

### Track 径迹筛选

主窗口顶部 **Track** 复选框（TGCheckButton），勾选后在分析画布额外施加径迹投影匹配。

**原理**：
1. 利用 PPAC 靶点 `(target_x, target_y, 0)` 和 D2 位置形成空间直线
2. 将直线投影到 D1、D3、D4 的 Z 平面，得到理论位置
3. 与各层实际位置比较，要求 |dx| < 2.0 mm 且 |dy| < 2.0 mm

**10C 径迹检查**（靶点 → D2_10C 直线）：

| 投影层 | 比较 |
|--------|------|
| D1 | \|pred\_x - t0d1\_10C\_x\| < 2.0, \|pred\_y - t0d1\_10C\_y\| < 2.0 |
| D3 | \|pred\_x - t0d3\_10C\_x\| < 2.0, \|pred\_y - t0d3\_10C\_y\| < 2.0 |

**4He 径迹检查**（靶点 → D2_4He 直线）：

| 投影层 | 比较 |
|--------|------|
| D1 | 仅当 d1_hit=2 时检查（同 10C） |
| D3 | \|pred\_x - t0d3\_4He\_x\| < 2.0, \|pred\_y - t0d3\_4He\_y\| < 2.0 |
| D4 | \|pred\_x - t0d4\_4He\_x\| < 2.0, \|pred\_y - t0d4\_4He\_y\| < 2.0 |

勾选 Track 后，status bar 显示 `Beam=xxx+Track`。

### TAFD 响应窗口（t1 触发专用）

仅当加载 **t1 触发** 的 extract 文件时会弹出此窗口。t1 触发信号由 TAFD 探测器给出，此窗口用于观察 TAFD 上粒子的能量-角度分布、TAFD 方法重建的 10C 激发能，以及 CsI-TAFD 关联。

**布局**：2×2 的独立 TCanvas：

```
┌──────────────────────────┬──────────────────────────┐
│  TAFD E-θ (t1)           │  10C E_x (TAFD d)        │
│  (θ_TAFD, E_TAFD)        │  (E_x_10C, counts)       │
│  colz + d 理论曲线        │  100 bins, [-20, 80] MeV │
├──────────────────────────┼──────────────────────────┤
│  CsI vs TAFD             │  （空白）                  │
│  (CsI_e, E_TAFD)         │                          │
│  colz                    │                          │
└──────────────────────────┴──────────────────────────┘
```

**Panel 1 — TAFD E-θ 关联**：

- 纵轴：TAFD 刻度能量 (MeV)，**不做靶内能损修正**
- 横轴：粒子从靶点到 TAFD 击中点与 z 轴的夹角 $\theta$ (deg)
- 叠加三条 $^{14}\text{O}(d,d')$ 反应中 deuteron 的理论 E-θ 曲线（激发态 12/18/22 MeV）
- 填充条件与 10C/4He 分析图完全一致（束流筛选、He4 stop/tran、Track 径迹匹配、ppac_valid）
- 无符合条件的 TAFD 事件时不填充

**Panel 2 — TAFD 方法 10C 激发能谱**：

利用 TAFD 上测量到的 deuteron 能量和角度，通过**动量守恒反推束流**的方法重建 10C 激发能，不依赖束流能量测量。

$$
\begin{aligned}
\vec{p}_{\text{total}} &= \vec{p}_{^{10}\text{C}} + \vec{p}_{^{4}\text{He}} + \vec{p}_{d,\text{TAFD}} \\
T_{^{14}\text{O}}^{\text{reco}} &= \sqrt{|\vec{p}_{\text{total}}|^2 + m_{^{14}\text{O}}^2} - m_{^{14}\text{O}} \\
E_x(^{10}\text{C}) &= T_{^{14}\text{O}}^{\text{reco}} + Q_0 - (T_{^{10}\text{C}} + T_{^{4}\text{He}} + T_{d,\text{TAFD}})
\end{aligned}
$$

其中 $Q_0 = m_{^{14}\text{O}} - m_{^{10}\text{C}} - m_{^{4}\text{He}}$。此方法为 beam-energy-independent，与现有束流能量法互相独立验证。分 bin 与主激发能谱 `h_excitation_10C` 一致：100 bins, [-20, 80] MeV。

**Panel 3 — CsI vs TAFD 关联**：

- 横轴：CsI 能量 (ADC channel, 100 bins, [0, 5000])
- 纵轴：TAFD 刻度能量 (MeV, 100 bins, [0, 15])
- 逻辑：先通过 `FindTafdTarget` 确定击中 TAFD，再读取同一 entry 的 `tafcsi_t1_<run>.root`，取对应两块 CsI 中较大的信号填入
- CsI 无信号时不填充

### P with PID 窗口（t1 触发专用，CH2 版）— p 能损修正与 PID

此窗口仅在 `GUI_10C_4He_CH2` 中存在，为 **3×2 布局**（1200×800），对所有填入 CsI-TAFD 关联图的数据点，进行质子(p)的能损修正并重新绘制 E-θ 和 ¹⁰C 激发能谱，并根据 ¹⁰C 激发能 gate 绘制 ¹⁴O 不变质量激发能谱。CsI 信号用于粒子鉴别（PID）。

#### 布局

```
┌──────────────────────────┬──────────────────────────┬──────────────────────────┐
│  1.  TAFD x-y (with CsI) │  2.  Corrected p E-θ     │  3.  ¹⁰C Ex (corrected p) │
│      x: 100 [-200, 200]  │      θ: 50 [0, 90]       │      200 bins [-20, 80]   │
│      y: 100 [-200, 200]  │      E: 100 [0, 100]     │      MeV                  │
├──────────────────────────┼──────────────────────────┼──────────────────────────┤
│  4.  ¹⁴O Ex gate [-1,1.5]│  5.  ¹⁴O Ex gate [1.5,6] │  6.  Overlay (blue + red) │
│      基态 gate             │      3.3 MeV 激发态 gate │      bin 同主窗口 Ex bins  │
│      E_x(¹⁴O) (MeV)       │      E_x(¹⁴O) (MeV)      │                          │
└──────────────────────────┴──────────────────────────┴──────────────────────────┘
```

**panel 1（左上）**：TAFD x-y 空间位置分布，与旧窗口相同。

**panel 2（上中）**：经能损修正后的质子(p) E-θ 散射分布：
- 横轴：θ_p (deg) — p 相对于 z 轴的散射角
- 纵轴：E_p,total (MeV) — 经硅穿透修正和 CH2 靶（180 μm）内能损补足后的 p 总能量

**panel 3（右上）**：经能损修正后的 ¹⁰C 激发能谱（200 bins, [-20, 80] MeV），动量守恒反推反冲 ¹⁴O → ¹⁰C+⁴He+p。

**panel 4–6（第二行）**：基于 ¹⁰C 激发能 gate 的 ¹⁴O 不变质量激发能谱：
- **Gate 1**（panel 4）：¹⁰C E_x ∈ [-1.0, 1.5] MeV（基态），蓝色
- **Gate 2**（panel 5）：¹⁰C E_x ∈ [1.5, 6.0] MeV（3.35 MeV 激发态），红色
- **Overlay**（panel 6）：两谱叠加对比，分 bin 数与主窗口 `excitation_bins` 控件一致

¹⁴O 激发能采用 **不变质量法**（¹⁰C+⁴He）计算，与主窗口方法一致：
- Gate 1（基态）：$E_x(¹⁴O) = M(P_{¹⁰C} + P_{⁴He}) - m_{¹⁴O}$

## 激发能计算原理

### 物理背景

14O 可以通过 α+10C 结构激发，其 α 分离阈值为 **E_break = 10.12 MeV**。当 14O 激发态衰变为 10C + α 时，通过测量两个碎片在实验室系中的四动量，可以利用不变质量法重建母核的激发能。

反应过程：
1. **第一步（两体反应）**：$^{14}\text{O} + d \to ^{14}\text{O}^* + d$，14O 在与氘靶相互作用中被激发
2. **第二步（衰变）**：$^{14}\text{O}^* \to ^{10}\text{C}^{(*)} + ^{4}\text{He}$，激发态 14O 衰变为 10C 和 α

此为 Type 3 级联反应（详见 [运动学理论基础](kinematics_theory.md#33-type-3-分场景重建-exc-和-exf)）。

### 10C 激发能重建

10C 只有两个束缚态：**基态**和 **$E_x = 3.35$ MeV 的 $2^+$ 态**。由于探测器分辨率限制，采用以下区间分类：

| 区间 | $E_x(^{10}\text{C})$ 范围 | 对应态 |
|:---|:---|:---|
| Gate 1（基态） | $[-2, 2]$ MeV | 基态 |
| Gate 2（激发态） | $[2, 7]$ MeV | 3.35 MeV $2^+$ 态 |

利用束流能量和动量守恒（近似 $\vec{p}_\gamma \approx 0$ 反推反冲氘核动量），通过动能差公式计算：

$$
E_x(^{10}\text{C}) = T_A + Q_0 - (T_{^{10}\text{C}} + T_{^{4}\text{He}} + T_D)
$$

其中 $Q_0 = m_{^{14}\text{O}} - m_{^{10}\text{C}} - m_{^{4}\text{He}}$，$T_A$ 为经靶内能损修正后的束流动能，$T_D$ 为动量守恒反推的反冲氘核动能。

### 14O 激发能重建（含 γ 光子修正）

**关键修正**：10C 激发态退激放出 $\gamma$ 光子（$E_\gamma = E_x(^{10}\text{C})$），其能量必须计入 14O 不变质量计算。

采用**共线近似**（$\vec{p}_\gamma \parallel \vec{p}_{^{10}\text{C}}$），重建 10C* 的四动量：

$$
P_{^{10}\text{C}^*} = P_{^{10}\text{C},gs} + P_\gamma, \quad P_\gamma = \big(E_x(^{10}\text{C}),\; E_x(^{10}\text{C})\,\hat{p}_{^{10}\text{C}}\big)
$$

修正后的 14O 激发能：

$$
E_x(^{14}\text{O}) = M(P_{^{10}\text{C}^*} + P_{^{4}\text{He}}) - m_{^{14}\text{O},gs}
$$

> **为何必须修正**：忽略 $P_\gamma$ 直接使用 $M(P_{^{10}\text{C},gs} + P_{^{4}\text{He}})$ 将导致 $E_x(^{14}\text{O})$ 偏差约 $\sim 0.8\,E_x(^{10}\text{C})$。对于 10C 的 3.35 MeV 激发态，偏差约 **2.7 MeV**——远超核谱学精度要求。

### 原子质量来源

通过 `brill::GetMass(6, 10)`、`brill::GetMass(2, 4)`、`brill::GetMass(8, 14)` 和 `brill::GetMass(1, 2)` 从 `assets/amdc_ion_2020.txt` 读取准确原子质量（单位：MeV/c²）。

### 代码实现

```cpp
double m_10C = brill::GetMass(6, 10);
double m_4He = brill::GetMass(2, 4);
double m_14O = brill::GetMass(8, 14);
double m_d   = brill::GetMass(1, 2);

// 能量损失修正后的动能
double T_10C_corr = /* ... */;
double T_4He_corr = /* ... */;

// 构建四动量
TLorentzVector P_10C(px_10C, py_10C, pz_10C, T_10C_corr + m_10C);
TLorentzVector P_4He(px_4He, py_4He, pz_4He, T_4He_corr + m_4He);

// Step 1: 计算 10C 激发能（动能差法）
double Q0 = m_14O - m_4He - m_10C;
double Q  = T_10C_corr + T_4He_corr + T_D - E_beam;
double E_x_10C = Q0 - Q;

// Step 2: 共线近似构造 γ 光子四动量
TVector3 p_10C_hat = P_10C.Vect().Unit();
TLorentzVector P_gamma(
    p_10C_hat.X() * E_x_10C,
    p_10C_hat.Y() * E_x_10C,
    p_10C_hat.Z() * E_x_10C,
    E_x_10C);

// Step 3: 重建 10C* 并计算 14O 激发能
TLorentzVector P_10C_star = P_10C + P_gamma;
TLorentzVector P_14O_reco = P_10C_star + P_4He;
double E_x_14O = P_14O_reco.M() - m_14O;
```
